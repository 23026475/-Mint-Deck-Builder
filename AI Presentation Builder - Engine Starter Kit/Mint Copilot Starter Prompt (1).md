# Mint Deck Starter Prompt (for Microsoft 365 Copilot)

**How to use:** Open `FY27 AI-Ready v3.0.potx` FIRST (File > New from the Mint template), then open
Copilot and paste the prompt below, filling the brackets. Never start from a blank file — Copilot
follows the open template's layouts and the 24 sample slides.

*(v3.0, 22 Jul 2026 — supersedes all earlier versions, which are in "Archive - Old Versions".)*

---

Create a presentation about [TOPIC] for [AUDIENCE], to be [read as a document / presented live].

Follow these rules exactly:

1. STORY ORDER — structure the deck as: (1) the shift happening in the client's world (full-bleed
   statement, never "about us" first); (2) the stakes — who wins and loses (cards or big stats);
   (3) our answer stated up front as one sentence (Thesis layout); (4) the client's future state
   with evidence (chart or stats); (5) how it works — only now the offering (cards, process flow,
   roadmap); (6) proof — case study, quote, client logos; (7) the ask — summary and next steps.
2. TITLES — every content slide title is a full-sentence takeaway of max 15 words, stating the
   slide's one message (like "Governance catches adoption by month 9"), never a topic label (like
   "Our approach"). Reading the titles alone must tell the complete story.
3. LAYOUTS — use this template's layouts by name; pick the layout that matches the content shape
   (comparison → Comparison; one number → KPI or Pricing; steps → Process Flow; dates → Roadmap).
   Fill every placeholder or delete it — never leave prompt text visible.
4. DENSITY — max 60 words per slide body (hard ceiling 90). Cards get 3–5 short points each.
   If presenting live: max 10 slides, nothing smaller than 24pt — use only the big-type layouts
   (Statement, Thesis, KPI, Quote, Chart, dividers, Closing).
5. CHARTS — one chart, one message, the takeaway as the headline; label data directly, no legends;
   highlight only the series that carries the message.
6. Include exactly ONE memorable moment: a shocking statistic or a bold one-line statement slide.
7. Never add logos, borders or colours — the template carries them. Keep the Mint palette untouched.
8. IMAGES — use only Mint's approved imagery from the Mint CI Elements library on the Marketing
   SharePoint site (Document Type = Imagery / Iconography); no external stock photos.
